# STM32 Interrupt-Driven Event Logger

## Overview

An embedded firmware project using Embedded C and an STM32 microcontroller to capture external interrupt events, store event records in a circular buffer, and transmit event information through UART.

## Technologies

- Embedded C
- STM32F4 Series
- STM32CubeIDE and STM32CubeMX
- STM32 HAL
- EXTI interrupts
- HAL tick timestamping
- UART serial communication

## Current Status

Firmware development in progress. Hardware validation and UART output testing are pending.

## Planned Features

- Capture external events using GPIO interrupts
- Record event IDs and timestamps
- Buffer events using a circular queue
- Transmit event logs over UART
